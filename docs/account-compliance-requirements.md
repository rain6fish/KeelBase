# 账号与合规 — 需求确认书

> 日期：2026-08-06
> 范围：SMS 手机号验证 / 用户自助注销 / 用户自助导出数据（① 账号与合规类）

---

## 1. 背景

基座已具备邮箱验证（AU-2）、忘记密码（AU-1）、多设备会话（AU-3）等账号能力，但手机号仅加密存储、无验证流程；用户侧无法自助注销或导出个人数据。本需求补齐国内 App 上架必备的合规能力。

## 2. 功能需求

### 2.1 SMS 手机号验证码

| # | 需求 | 说明 |
|---|------|------|
| S1 | 发送短信验证码 | 用户输入手机号 → 下发 6 位验证码（10 分钟有效，5 分钟内同手机号限 1 次） |
| S2 | 绑定/更新手机号 | 登录用户验证码校验通过后绑定手机号；重复绑定校验占用（防他人绑定） |
| S3 | 手机号验证码登录 | 手机号 + 验证码直接登录（无密码账号可用）；未注册手机号是否自动注册由配置决定（默认不自动注册，避免撞库） |
| S4 | 防枚举 | 发送验证码统一响应（不暴露手机号是否已注册）；限流（5 次/分钟/手机号，全局 20 次/分钟） |
| S5 | 服务商抽象 | `SMS_DRIVER=console`（默认，验证码打印到日志，便于本地开发/测试）；`aliyun` 预留（需凭据） |

### 2.2 用户自助注销账号

| # | 需求 | 说明 |
|---|------|------|
| D1 | 注销入口 | 登录用户可申请注销（`POST /auth/deactivate`） |
| D2 | 安全确认 | 需提交当前密码（本地账号）校验，防误删/盗号注销 |
| D3 | 级联清理 | 删除用户后清理：登录会话、通知、AI 对话/消息、待办、事件、设备推送 token、操作审计关联 |
| D4 | 保护 | 不能注销最后一个管理员（复用现有守卫逻辑）；注销后所有已签发 token 失效（清会话 + refreshTokenHash） |
| D5 | 幂等 | 用户已不存在时返回成功（统一响应，不泄露状态） |

### 2.3 用户自助导出数据

| # | 需求 | 说明 |
|---|------|------|
| E1 | 导出本人数据 | 登录用户导出本人全量数据（`GET /auth/export-data`），返回 JSON |
| E2 | 内容 | profile（脱敏不含密钥）+ 事件 + 待办 + AI 对话 + 通知 + AI 用量统计 |
| E3 | 权限 | 仅本人可见（JWT 校验），不经过管理端接口 |

## 3. 非目标（本批不做）

- 短信服务商真实对接（SMS 凭据到位的后续项，抽象已就绪）
- 注销冷静期/二次确认流程（当前一次确认 + 密码校验）
- 导出格式自定义（固定 JSON）

## 4. 约束与红线

- 遵循 CLAUDE.md §5.5：手机号在服务端加密存储 + 派生 hash 查询；接口统一响应
- 防枚举语义与现有 forgot-password / verify-email 一致
- 新实体需生成迁移（sqlite + postgres 双语迁移，CI 一致性校验）
